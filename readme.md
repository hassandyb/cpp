# C++ Modules From 00 to 04 Overview

Welcome to the overview of our C++ modules! This documentation provides a summary of what each module covers and what you can expect to learn from them.

## C++ - Module 00: Basics of C++

### Overview
Module 00 introduces the foundational elements of C++. You'll cover essential concepts such as namespaces, classes, and member functions, as well as some basic programming techniques.

### Key Concepts
- **Namespaces:** Learn how to organize code and avoid naming conflicts using namespaces.
- **Classes:** Understand how to define and use classes to create objects.
- **Member Functions:** Explore how to define functions within classes to operate on class data.
- **Stdio Streams:** Get familiar with input and output operations using standard streams.
- **Initialization Lists:** Use initialization lists to initialize class members.
- **Static and Const:** Learn about `static` and `const` keywords and their uses in C++.

### Learning Outcomes
- Organize code with namespaces and classes.
- Use member functions, streams, and initialization lists effectively.

---

## C++ - Module 01: Memory Management and Pointers

### Overview
Module 01 delves into memory management and the use of pointers in C++. You'll learn how to manage dynamic memory and work with pointers to members.

### Key Concepts
- **Memory Allocation:** Understand dynamic memory allocation with `new` and `delete`.
- **Pointers to Members:** Learn how to use pointers to member functions and data.
- **References:** Explore how to use references for efficient data manipulation.
- **Switch Statement:** Use `switch` statements to simplify multi-way branching.

### Learning Outcomes
- Manage memory effectively with dynamic allocation.
- Utilize pointers and references to manipulate data and functions.

---

## C++ - Module 02: Ad-hoc Polymorphism and Operator Overloading

### Overview
In Module 02, you'll explore ad-hoc polymorphism and operator overloading. These concepts help you define how operators work with user-defined types and improve code flexibility.

### Key Concepts
- **Ad-hoc Polymorphism:** Learn how to use function overloading to define multiple functions with the same name but different parameters.
- **Operator Overloading:** Customize how operators work with your classes to enhance usability.
- **Orthodox Canonical Class Form:** Understand the canonical form for defining classes with constructors, destructors, and assignment operators.

### Learning Outcomes
- Define overloaded functions and operators for user-defined types.
- Implement the Orthodox Canonical Class Form for class management.

---

## C++ - Module 03: Inheritance

### Overview
Module 03 focuses on inheritance, a key feature in object-oriented programming. You'll learn how to create hierarchies of classes and reuse code effectively.

### Key Concepts
- **Inheritance:** Understand how to derive new classes from existing ones, allowing for code reuse and extension.
- **Base and Derived Classes:** Explore how to create base classes and derive new classes from them.
- **Access Specifiers:** Learn about access control with `public`, `protected`, and `private`.

### Learning Outcomes
- Utilize inheritance to create class hierarchies and reuse code.
- Manage access to class members with appropriate access specifiers.

---

## C++ - Module 04: Polymorphism and Abstract Classes

### Overview
In Module 04, you'll study subtype polymorphism, abstract classes, and interfaces. These concepts are essential for designing flexible and reusable software components.

### Key Concepts
- **Subtype Polymorphism:** Learn how to use polymorphism to treat objects of different derived classes through a common base class.
- **Abstract Classes:** Understand abstract classes and how they define common interfaces for derived classes.
- **Interfaces:** Explore how to use pure virtual functions to define interfaces for implementation by derived classes.

### Learning Outcomes
- Implement polymorphism to handle different types through a common interface.
- Define and use abstract classes and interfaces to design flexible and reusable code.
